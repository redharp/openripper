Folders & naming

Movie and TV paths apply in both output modes. Check the media type before starting a disc with an uncertain name.

Output naming

Use {disc}, {title}, {year}, and {job_id}. Keep {job_id} for collision protection.

{title}{year_suffix}{edition_suffix}. The .mkv extension is added automatically.

{title}, {season:02d}, {episode:02d}, {episode_suffix}. Season folders are created automatically.

Drive destinations

Give a drive its own output root. Leave blank to use the default. Both modes create Movies and TV below each override.

Artwork

Save a poster beside completed video and show it in the dashboard. No image is guessed when the match is uncertain.

Poster artwork

Requires a TMDB API read token on the server.

Set OPENRIPPER_TMDB_TOKEN on the server. Disc titles are sent to TMDB only when matching or artwork is enabled. This product uses the TMDB API but is not endorsed or certified by TMDB.

HandBrake

Optional encoding after the disc is copied. Off by default. Encoding uses the same job slot and can be CPU intensive.

Optional HandBrake encoding

Install the CLI separately on this host.

Presets come from the saved HandBrake CLI executable. Save a changed executable path before refreshing. The preset controls video quality and resolution. Output is MKV with retained audio/subtitles where supported; unsupported audio may be converted to AAC.

Originals are always kept on failure. In library mode, retained originals stay in staging. In disc mode, both versions are kept in the disc folder.

Exact movie matches can run automatically. Other matches and TV episode assignments need confirmation in History → Details → Process names. Extras stay with the original rip.
